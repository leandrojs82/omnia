# OmnIA Fase 1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar `index.html` — um site single-file, sem build e sem backend, com o core (registry, router, busca, UI kit, persistência) e 24 ferramentas funcionais.

**Architecture:** Um único arquivo HTML com três camadas mentais: `OmnIA.lib` (funções puras, sem DOM — é o que os testes exercitam), o core (registry + router + UI kit + storage) e `TOOLS[]` (o array de ferramentas). Cada ferramenta é um objeto autocontido; nenhuma conhece outra.

**Tech Stack:** HTML5, CSS3 (custom properties), JavaScript ES2020 vanilla. Zero dependências, zero build, zero npm.

## Global Constraints

- **Um único arquivo entregável:** `index.html`. Todo CSS em `<style>`, todo JS em `<script>`. Nenhum `import`, nenhum `<script src>` externo, nenhum `type="module"` (quebra em `file://` por CORS).
- **Abre com duplo clique:** tudo deve funcionar via protocolo `file://`, sem servidor.
- **Idioma:** toda a interface em português do Brasil.
- **Cores:** nenhuma cor hardcoded fora dos tokens `:root`. Tema claro redefine apenas os tokens sob `[data-tema="light"]`.
- **localStorage:** todo acesso envolvido em `try/catch`. O site funciona com storage bloqueado.
- **Chaves de storage:** exatamente `omnia.favoritos`, `omnia.recentes`, `omnia.tema`, `omnia.notepad`.
- **Selos de ferramenta:** `tipo` é exatamente uma das strings `'nativa'`, `'online'`, `'script'`.
- **Nenhum resultado falso.** Se o browser não faz, a ferramenta gera o script que faz.
- **Sem rolagem horizontal na página** em 375px. Conteúdo largo rola dentro do próprio container.
- **Datas:** toda data criada a partir de string `YYYY-MM-DD` deve usar `lib.parseData()` (Task 10), que ancora ao meio-dia local para evitar erro de fuso. Nunca usar `new Date("2026-01-01")` direto.

## Estratégia de teste

Não há npm, logo não há Jest. O teste é um **runner embutido no próprio arquivo**, o que mantém o TDD real e verificável:

- `OmnIA.lib` contém apenas funções puras (entra valor, sai valor, sem DOM).
- `TESTES[]` é um array de `{ nome, fn }`. `fn` lança exceção ao falhar.
- A rota `#/_testes` renderiza o resultado: verde para passou, vermelho com a mensagem para falhou, e um placar `N/M`.
- **Como rodar:** abrir `index.html#/_testes` no browser e ler o placar. Recarregar a página (Ctrl+R) roda tudo de novo.

Essa rota é interna: não aparece na sidebar nem na busca.

**Interfaces:**

Criar `index.html`:

```html
<!doctype html>
<html lang="pt-BR" data-tema="dark">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>OmnIA — Canivete Suíço Digital</title>
<style>
/* tokens e layout entram na Task 1 */
body { margin: 0; font-family: system-ui, sans-serif; }
</style>
</head>
<body>
<div id="app">OmnIA</div>
<script>
"use strict";
const OmnIA = { lib: {} };
const lib = OmnIA.lib;

/* ---------- runner de testes ---------- */
const TESTES = [];

function assertEq(atual, esperado, msg) {
  const a = JSON.stringify(atual), e = JSON.stringify(esperado);
  if (a !== e) throw new Error((msg ? msg + ": " : "") + "esperado " + e + ", recebeu " + a);
}

function assertTrue(valor, msg) {
  if (!valor) throw new Error(msg || "esperado valor verdadeiro, recebeu " + JSON.stringify(valor));
}

function rodarTestes() {
  const falhas = [];
  let passou = 0;
  for (const t of TESTES) {
    try { t.fn(); passou++; }
    catch (e) { falhas.push({ nome: t.nome, erro: e.message }); }
  }
  return { passou, total: TESTES.length, falhas };
}

TESTES.push({ nome: "runner funciona", fn: () => assertEq(1 + 1, 2) });

/* ---------- render provisório do runner ---------- */
function renderTestes(el) {
  const r = rodarTestes();
  const linhas = r.falhas.map(f =>
    '<li style="color:#f87171">✗ ' + f.nome + ' — ' + f.erro + '</li>'
  ).join("");
  el.innerHTML =
    '<h1>Testes: ' + r.passou + '/' + r.total + '</h1>' +
    (r.falhas.length ? '<ul>' + linhas + '</ul>' : '<p style="color:#4ade80">Todos passaram.</p>');
}

if (location.hash === "#/_testes") renderTestes(document.getElementById("app"));
window.addEventListener("hashchange", () => location.reload());
</script>
</body>
</html>
```

  - `ui.area(label, attrs={})` → `HTMLTextAreaElement` (mesma convenção)

  - `ui.linha(...nós)` → `HTMLDivElement` flex com os filhos
  - `ui.montar(el, ...nós)` → anexa nós (usando `.wrapper` quando existir) em `el`

```js
lib.inverter = s => [...(s || "")].reverse().join("");

lib.caixa = (s, modo) => {
  s = s || "";
  switch (modo) {
    case "maiuscula": return s.toUpperCase();
    case "minuscula": return s.toLowerCase();
    case "titulo": return s.toLowerCase().replace(/(^|\s)(\S)/g, (m, a, b) => a + b.toUpperCase());
    case "frase": return s.toLowerCase().replace(/(^\s*|[.!?]\s+)(\S)/g, (m, a, b) => a + b.toUpperCase());
    case "alternada": return [...s].map((c, i) => i % 2 ? c.toLowerCase() : c.toUpperCase()).join("");
    default: return s;
  }
};

lib.removerDuplicadas = (s, ignorarCaixa = false) => {
  const vistos = new Set();
  return (s || "").split("\n").filter(l => {
    const k = ignorarCaixa ? l.toLowerCase() : l;
    if (vistos.has(k)) return false;
    vistos.add(k); return true;
  }).join("\n");
};

lib.ordenar = (s, decrescente = false) => {
  const ls = (s || "").split("\n").sort((a, b) => a.localeCompare(b, "pt-BR"));
  return (decrescente ? ls.reverse() : ls).join("\n");
};

lib.substituir = (s, busca, troca, op = {}) => {
  if (!busca) return s || "";
  const flags = "g" + (op.sensivel ? "" : "i");
  const padrao = op.regex ? busca : busca.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
  return (s || "").replace(new RegExp(padrao, flags), troca);
};
```

```js
lib.cesar = (s, d) => {
  const n = ((d % 26) + 26) % 26;
  return (s || "").replace(/[a-z]/g, c =>
      String.fromCharCode((c.charCodeAt(0) - 97 + n) % 26 + 97))
    .replace(/[A-Z]/g, c =>
      String.fromCharCode((c.charCodeAt(0) - 65 + n) % 26 + 65));
```

```js
const DIA_MS = 86400000;

lib.parseData = iso => {
  const m = /^(\d{4})-(\d{2})-(\d{2})$/.exec((iso || "").trim());
  if (!m) throw new Error("Data inválida: " + iso);
  const d = new Date(+m[1], +m[2] - 1, +m[3], 12, 0, 0, 0);
  if (d.getMonth() !== +m[2] - 1) throw new Error("Data inexistente: " + iso);
  return d;
};

lib.hojeIso = () => {
  const d = new Date();
  return d.getFullYear() + "-" +
    String(d.getMonth() + 1).padStart(2, "0") + "-" +
    String(d.getDate()).padStart(2, "0");
};

lib.diasEntre = (a, b) =>
  Math.round(Math.abs(lib.parseData(b) - lib.parseData(a)) / DIA_MS);

lib.idadeExata = (nascIso, refIso) => {
  const n = lib.parseData(nascIso), r = lib.parseData(refIso || lib.hojeIso());
  if (r < n) throw new Error("A data de referência é anterior ao nascimento.");
  let anos = r.getFullYear() - n.getFullYear();
  let meses = r.getMonth() - n.getMonth();
  let dias = r.getDate() - n.getDate();
  if (dias < 0) {
    meses--;
    dias += new Date(r.getFullYear(), r.getMonth(), 0).getDate();
  }
  if (meses < 0) { anos--; meses += 12; }
  return { anos, meses, dias, totalDias: Math.round((r - n) / DIA_MS) };
};

lib.diasUteis = (aIso, bIso, feriados = []) => {
  let a = lib.parseData(aIso), b = lib.parseData(bIso);
  if (a > b) [a, b] = [b, a];
  const fer = new Set(feriados.map(f => f.trim()).filter(Boolean));
  let n = 0;
  for (const d = new Date(a); d <= b; d.setDate(d.getDate() + 1)) {
    const dow = d.getDay();
    if (dow === 0 || dow === 6) continue;
    const iso = d.getFullYear() + "-" +
      String(d.getMonth() + 1).padStart(2, "0") + "-" +
      String(d.getDate()).padStart(2, "0");
    if (!fer.has(iso)) n++;
  }
  return n;
};
```

```js
lib.regraDeTres = (a, b, c) => {
  if (!a) throw new Error("O primeiro valor não pode ser zero.");
  return (b * c) / a;
};

lib.porcentagem = (modo, x, y) => {
  if (modo === "de") return (x / 100) * y;
  if (modo === "quantoE") {
    if (!y) throw new Error("O total não pode ser zero.");
    return (x / y) * 100;
  }
  if (modo === "variacao") {
    if (!x) throw new Error("O valor inicial não pode ser zero.");
    return ((y - x) / x) * 100;
  }
  throw new Error("Modo inválido");
};

const ROMANOS = [
  [1000,"M"],[900,"CM"],[500,"D"],[400,"CD"],[100,"C"],[90,"XC"],
  [50,"L"],[40,"XL"],[10,"X"],[9,"IX"],[5,"V"],[4,"IV"],[1,"I"]
];

lib.paraRomano = n => {
  n = Math.floor(n);
  if (!(n >= 1 && n <= 3999)) throw new Error("Use um número inteiro de 1 a 3999.");
  let r = "";
  for (const [v, s] of ROMANOS) while (n >= v) { r += s; n -= v; }
  return r;
};

lib.deRomano = s => {
  s = (s || "").toUpperCase().trim();
  if (!/^[MDCLXVI]+$/.test(s)) throw new Error("Use apenas M D C L X V I.");
  const val = { I:1, V:5, X:10, L:50, C:100, D:500, M:1000 };
  let n = 0;
  for (let i = 0; i < s.length; i++) {
    const a = val[s[i]], b = val[s[i + 1]] || 0;
    n += a < b ? -a : a;
  }
  if (lib.paraRomano(n) !== s) throw new Error("Numeral romano mal formado.");
  return n;
};

lib.converterBase = (valor, de, para) => {
  const n = parseInt((valor || "").trim(), de);
  if (isNaN(n)) throw new Error("Valor inválido para a base " + de + ".");
  return n.toString(para).toUpperCase();
};
```

```js
const soDigitos = s => (s || "").replace(/\D/g, "");

lib.validarCPF = s => {
  const c = soDigitos(s);
  if (c.length !== 11 || /^(\d)\1{10}$/.test(c)) return false;
  for (let t = 9; t < 11; t++) {
    let soma = 0;
    for (let i = 0; i < t; i++) soma += +c[i] * (t + 1 - i);
    let d = (soma * 10) % 11;
    if (d === 10) d = 0;
    if (d !== +c[t]) return false;
  }
  return true;
};

lib.gerarCPF = (formatado = true) => {
  const n = Array.from({ length: 9 }, () => Math.floor(Math.random() * 10));
  for (let t = 9; t < 11; t++) {
    let soma = 0;
    for (let i = 0; i < t; i++) soma += n[i] * (t + 1 - i);
    let d = (soma * 10) % 11;
    n.push(d === 10 ? 0 : d);
  }
  const c = n.join("");
  if (/^(\d)\1{10}$/.test(c)) return lib.gerarCPF(formatado);
  return formatado ? c.replace(/(\d{3})(\d{3})(\d{3})(\d{2})/, "$1.$2.$3-$4") : c;
};

const PESOS_CNPJ = [6,5,4,3,2,9,8,7,6,5,4,3,2];

lib.validarCNPJ = s => {
  const c = soDigitos(s);
  if (c.length !== 14 || /^(\d)\1{13}$/.test(c)) return false;
  for (let t = 12; t < 14; t++) {
    const pesos = PESOS_CNPJ.slice(13 - t);
    let soma = 0;
    for (let i = 0; i < t; i++) soma += +c[i] * pesos[i];
    const r = soma % 11;
    if ((r < 2 ? 0 : 11 - r) !== +c[t]) return false;
  }
  return true;
};

lib.gerarCNPJ = (formatado = true) => {
  const n = Array.from({ length: 8 }, () => Math.floor(Math.random() * 10))
    .concat([0, 0, 0, 1]);
  for (let t = 12; t < 14; t++) {
    const pesos = PESOS_CNPJ.slice(13 - t);
    let soma = 0;
    for (let i = 0; i < t; i++) soma += n[i] * pesos[i];
    const r = soma % 11;
    n.push(r < 2 ? 0 : 11 - r);
  }
  const c = n.join("");
  return formatado ? c.replace(/(\d{2})(\d{3})(\d{3})(\d{4})(\d{2})/, "$1.$2.$3/$4-$5") : c;
};

lib.uuidV4 = () => {
  if (crypto.randomUUID) return crypto.randomUUID();
  const b = crypto.getRandomValues(new Uint8Array(16));
  b[6] = (b[6] & 0x0f) | 0x40;
  b[8] = (b[8] & 0x3f) | 0x80;
  const h = [...b].map(x => x.toString(16).padStart(2, "0")).join("");
  return h.slice(0,8)+"-"+h.slice(8,12)+"-"+h.slice(12,16)+"-"+h.slice(16,20)+"-"+h.slice(20);
};
```

```js
lib.imc = (peso, altura) => {
  if (!(peso > 0) || !(altura > 0)) throw new Error("Informe peso e altura maiores que zero.");
  const v = Math.round((peso / (altura * altura)) * 100) / 100;
  const classificacao =
    v < 18.5 ? "Abaixo do peso" :
    v < 25   ? "Peso normal" :
    v < 30   ? "Sobrepeso" :
    v < 35   ? "Obesidade grau I" :
    v < 40   ? "Obesidade grau II" : "Obesidade grau III";
  return { valor: v, classificacao };
};
```
